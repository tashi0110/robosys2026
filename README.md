# robosys2026

アルバイトの月収を計算するコマンド `shiftcalc` を提供します。

## Commands

### shiftcalc

指定した年月・時給・曜日ごとの勤務時間から、月間の勤務日数、合計勤務時間、予想給与を計算します。

#### Requirements

- Python 3.10〜3.14

#### Usage

年・月・時給をコマンドライン引数で指定し、曜日ごとの勤務時間を標準入力から入力します。

```bash
$ ./shiftcalc 2026 11 1200
月曜日 5
水曜日 4
金曜日 6
土曜日 8
```

入力が終わったら `Ctrl + D` を押してください。

また、勤務時間をファイルに保存して読み込むこともできます。

```bash
$ ./shiftcalc 2026 11 1200 < shifts.txt
```

#### Arguments

| 引数 | 内容 |
|---|---|
| 第1引数 | 年 |
| 第2引数 | 月 |
| 第3引数 | 時給（円） |

#### Input

標準入力には、曜日とその曜日の勤務時間を1行ずつ指定します。

```text
月曜日 5
水曜日 4
金曜日 6
土曜日 8
```

- 曜日と勤務時間を空白で区切ります。
- 勤務しない曜日は省略できます。
- 年は1~9999、月は1~12で指定してください。
- 時給は0より大きい数値を指定してください。
- 勤務時間は0~24の数値を指定してください。

#### Output

計算結果はCSV形式で標準出力に出力されます。

```text
month,workdays,total_hours,wage_yen
2026-11,17,97,116400
```

| 項目 | 内容 |
|---|---|
| month | 対象年月 |
| workdays | 月間勤務日数 |
| total_hours | 合計勤務時間 |
| wage_yen | 予想給与（円） |

入力に誤りがある場合は、エラーメッセージを標準エラー出力に表示します。

#### Testing

以下のコマンドでテストを実行できます。

```bash
$ bash -xv ./test_shiftcalc.bash
```
